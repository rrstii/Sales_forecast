# پیش‌بینی فروش روزانه با رگرسیون خطی

پروژه کوچیک برای پیش‌بینی فروش روزانه یک فروشگاه با استفاده از ویژگی‌های تاخیری (lag features) و رگرسیون خطی. نتیجه با یک baseline ساده (فرض تکرار فروش روز قبل) مقایسه شده تا مشخص بشه مدل واقعاً ارزش اضافه داره یا نه.

## اجرا
```
pip install pandas numpy matplotlib scikit-learn
python forecast.py
```

## نکته
داده فعلی مصنوعیه (روند + نوسان هفتگی + نویز) چون دیتای واقعی در دسترس نبود. برای استفاده روی داده واقعی، کافیه `make_fake_data()` رو با خواندن یک فایل csv با ستون‌های `date` و `sales` جایگزین کنی.

## نتایج نمونه
- MAE مدل: ~7
- MAE baseline: ~13
- بهبود نسبت به baseline: ~۴۸٪
